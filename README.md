<h1>Welcome to the MotoCompanion-PWA wiki!</h1>
MotoCompanion is a simple app for motorcycle riders.

<h2>Installation</h2>
<ol>
<li>Clone the repository</li>
<li>Run <code>npm install</code> to install dependencies</li>
<li>Run <code>ionic serve</code> to launch the app in the browser</li>
</ol>

<h2>Technologies used</h2>
This project was made in Angular with Ionic. 
APIs used:
<ul>
<li>https://nominatim.org/ for getting locations name</li>
<li>https://open-meteo.com/ for the weather data</li>
<li>https://open-meteo.com/ for the weather data</li>
<li>https://gnews.io/ for the news data</li>
</ul>
